Notes

  1. Tiers, not models: actions name a tier (fast or quality, PLAN 5.3); this is where a tier gets its model. With only the fast model installed, the quality row reads "Uses the fast model (install Quality for better rewrites)".
  2. Installed models with the memory they take while loaded, measured in M0 (peak resident memory). "Ready, verified" means the SHA-256 matched. Remove asks once, in place, and frees the disk space.
  3. The speed-up is the multi-token-prediction draft head for each Gemma model (M0: proofread 26% faster on an 8 GB laptop, identical output). It is on by default and listed so it is never a hidden download.
  4. Languages (PLAN 3.1: the UI must say which languages the installed model handles well): "Tested" only for languages with a full eval set and a passed floor check; everything else is "Best effort". The list comes from models.json languages, not from a vendor's claims.
