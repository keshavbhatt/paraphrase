Notes

  1. The hardware probe (PLAN D9) runs before this step: memory, cores, CPU features, a Vulkan device. When the iGPU measures slower than the CPU (as on the M0 laptop) it is named but not used, so nobody wonders why their graphics chip sits idle.
  2. Fast is preselected and is the only model needed. Quality is offered, never pushed, and its card says plainly that it wants 16 GB. On an 8 GB computer the Quality card reads "Too large for this computer's memory" and stays unticked.
  3. Estimates are per computer, from a short timing run after the probe, rounded to whole seconds. They are estimates, so they say "about".
  4. The exact source (PLAN 8): the upstream repository, the pinned version and the SHA-256 check, so a careful user can verify the download. Pause and resume work across restarts. If the check fails, the file is deleted and the panel says so with a Retry button.
