Notes

  1. Standalone first (ADR-013, PLAN D14): this window needs nothing from the desktop but a window and the clipboard while it has focus, so it works in every package format and session. The notice appears only when an integration is missing, names the missing piece in plain words, and can be hidden; it never blocks anything.
  2. The same actions as the popup, the same skills: Ctrl+1 to Ctrl+7 pick one. Tone, Format, Translate and My actions open a short menu of their presets. Running an action on new text replaces the result; the text on the left is never changed by the app.
  3. Your text: type or paste, any length up to the skill's limit (a longer text gets a clear message, or is split for Summarize). The language is detected as you type and shown next to the word count; that is the language the result is written in, unless Translate is picked.
  4. The result streams in as the model writes. For Proofread it is the word diff with one line per change and Undo, as in the popup (PLAN D6); for Tone it shows versions and the facts kept; for Reply see the reply mock.
  5. Copy result is the main action here (the popup's is Replace). "Use as my text" moves the result to the left so the user can run another action on it, for example Proofread then Tone. Nothing is ever typed into another app from this window.
  6. Status line: which model answers and the memory it takes; the daemon starts when this window needs it and stops after a quiet period (ADR-010). Narrow windows stack the two panes.
  7. Result tab (approved 2026-10-27): only the corrected text, using the whole height of the pane, so it can be read in one go. The list of changes with Undo is on the Changes tab only; an Undo made there shows in Result. The popup's Result does the same.
  8. The split between the panes (approved 2026-10-27): drag it to make either pane wider. While the pointer is over it, or drags it, a short grip shows, as on the split in Reply; otherwise it is invisible. When the panes stack in a narrow window the grip turns across.
  9. A split on Changes (approved 2026-10-27) between the marked-up text and the list of changes: the list starts at the height its rows need (as now, up to 220px), and dragging the split gives the list more room for a text with many changes, or the text more. No line until the pointer is over it; the list keeps at least two rows; the place is kept. The popup keeps its fitted list, as it sizes itself to its content.
