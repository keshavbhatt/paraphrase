Notes

  1. Summary first: how many changes, and that the language was kept. The engine checks the language of every result (skill schema v2) and retries once if it changed; if the retry also changes it, a yellow "This may not be in English" pill replaces "kept in English" and Replace is still allowed, never hidden.
  2. The diff (PLAN D6): the model returns the whole corrected text, the client computes a word diff. Deletions are orange and struck out, insertions blue and underlined: different lightness as well as hue, and the strike-through and underline carry the meaning without colour. While the model is still writing, the corrected text streams in and the diff fills in behind it.
  3. One line per change, with Undo. Undo reverts only that change, so a wrong fix (a name, a handle, a British spelling) never forces the user to throw away the rest. The short reason comes from the diff category (spelling, punctuation, capital letter), not from the model.
  4. Replace types the result into the app the text came from (the remembered window); Enter does the same. Copy puts it on the clipboard; Retry runs again with a new seed. "Result" switches to the clean corrected text.
  5. No change needed: the panel says "Looks good, no changes" and offers only Close, so the user is never asked to replace text with itself.
