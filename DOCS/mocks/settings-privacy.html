Notes

  1. Off by default (PLAN D13). With it off, nothing the user writes outlives the window or popup it was written in: no file, no log, no cache of text.
  2. On: every finished run in the main window or the popup keeps one entry: the action, the text, the result the user saw last (the edited one when they edited it, the version they copied or replaced with), the app it came from, and the time. Stopped and failed runs are not kept. A run that only read ahead is never kept.
  3. Keep entries for 7 days, 30 days (the default), 1 year or until deleted; older entries go on their own, when the app starts and once a day.
  4. Not from these apps: password managers are listed from the start (KeePassXC, Bitwarden, 1Password, KeePass), and the user adds others; the popup knows the app a text came from. The main window has no app, so its runs are always kept while history is on.
  5. Where: an encrypted SQLite file in the app's data folder, its key in the system keyring (KWallet, GNOME Keyring through the Secret portal); without a keyring the switch stays off and says why. "Delete all history" removes the file and its key.
  6. Asked on the page, not in a dialog: Delete all, or Keep them. Turning history off asks the same question ("Delete the 142 entries kept so far?"), with Keep them as the default.
