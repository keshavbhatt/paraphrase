Notes

  1. Your actions (PLAN 3, custom.*): each is a preset of the built-in "custom" skill, kept in the user's config folder, never shared. In the window and the popup they sit under My actions, in this order; the menu ends with "New action..." which opens this page. Up to 20.
  2. Delete asks once in place: the button turns into "Delete?" at the same width, so nothing moves, and a second click deletes. It is never silent.
  3. What it does is the user's own instruction, up to 600 characters. The text the action works on is fenced as data, as for every skill, so text that contains instructions cannot take over. The result keeps the language of the text.
  4. Try it runs the action on a short sample (or on what is in the main window's text box) before saving, so the user sees what it does.
