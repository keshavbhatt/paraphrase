Notes

  1. The language follows the message: here Hinglish (Hindi in Latin letters), so the replies are Hinglish too, never English or Devanagari. The pill shows the detected language; for a language Paraphrase has not tested it reads "Best effort" next to the name.
  2. Written as the user: replies answer the message, they never speak for the sender (the "wrong side" failure the M0 spot-check counted).
  3. Three replies from one run of the model (PLAN 3.1), so they differ: typically agree, ask or suggest, decline or defer. Number keys 1 to 3 pick one into the edit box; Enter inserts it. If the engine's language check fails on a reply after its one retry, that reply carries a small "Not in Hinglish?" note instead of being dropped.
  4. Insert reply types into the app's message box (the remembered window); it is never sent. Sending stays the user's action (CLAUDE.md: never send text without an explicit user action). "3 new ones" runs again.
